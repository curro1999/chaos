# Chaos: interactive notes

Three small browser simulators for the ideas at the root of chaos theory.

Live site: https://curro1999.github.io/chaos/

| Page | What it shows |
|---|---|
| [The logistic map](https://curro1999.github.io/chaos/logistic-map-explorer.html) | Robert May's population rule, from stability to oscillation to chaos |
| [Period doubling and chaos](https://curro1999.github.io/chaos/bifurcation-diagram-explorer.html) | The bifurcation diagram of the logistic map, with zoom |
| [The Lorenz attractor](https://curro1999.github.io/chaos/lorenz-twin-trajectories.html) | Two nearly identical trajectories and sensitive dependence on initial conditions |

Each page is a single self-contained HTML file with no build step.

## Sources

- R. M. May, "Simple mathematical models with very complicated dynamics", Nature 261, 459–467 (1976).
- E. N. Lorenz, "Deterministic nonperiodic flow", Journal of the Atmospheric Sciences 20, 130–141 (1963).
